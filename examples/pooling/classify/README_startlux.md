# StartLux-Decision on vLLM v0.26.0

This patch adds native last-token decision pooling for Qwen3.5 dense and MoE
models, with eager and exact-length graph execution. Validated model sizes
and deployment commands are listed in the
[deployment guide](https://gitcode.com/Ascend-SACT/startlux_decision/blob/main/README.md).
